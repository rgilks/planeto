# PWA Configuration

This document outlines the Progressive Web App (PWA) configuration for the Planeto application.

## `next-pwa` Integration

The `next-pwa` library is used to enable PWA capabilities. It's configured in `next.config.ts`:

```typescript
import type { NextConfig } from "next";
import withPWA from "next-pwa";

const nextConfig: NextConfig = {
  output: "standalone",
  /* config options here */
};

export default withPWA({
  dest: "public",
  register: true,
  skipWaiting: true,
})(nextConfig);
```

- `dest: "public"`: Specifies that the service worker and other PWA files should be output to the `public` directory.
- `register: true`: Automatically registers the service worker.
- `skipWaiting: true`: Forces the waiting service worker to become the active service worker.

## Web App Manifest

A Web App Manifest is provided at `public/manifest.json`. This JSON file gives information about the application, such as its name, icons, start URL, display mode, and theme colors.

```json
{
  "name": "Planeto",
  "short_name": "Planeto",
  "icons": [
    {
      "src": "/icons/icon-192x192.png",
      "sizes": "192x192",
      "type": "image/png"
    },
    {
      "src": "/icons/icon-512x512.png",
      "sizes": "512x512",
      "type": "image/png"
    }
  ],
  "theme_color": "#000000",
  "background_color": "#000000",
  "start_url": "/",
  "display": "standalone",
  "orientation": "portrait"
}
```

## Icons

Placeholder icons are located in the `public/icons/` directory:

- `icon-192x192.png`
- `icon-512x512.png`

These should be replaced with the actual application icons.

## Service Worker

`next-pwa` handles the generation and registration of the service worker. This allows the application to work offline (by caching assets) and provides other PWA features.

## Linking the Manifest

The manifest file is linked in the root layout (`src/app/layout.tsx`) using a `<link>` tag in the `<head>`:

```tsx
export const metadata: Metadata = {
  title: "Create Next App",
  description: "Generated by create next app",
  manifest: "/manifest.json",
};
```
